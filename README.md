# PictureTagger

Локальное веб-приложение для просмотра изображений, быстрого тегирования и создания динамических коллекций по тегам.

## Возможности
- Выбор любой локальной папки (встроенный проводник или системный диалог Windows), опциональное сканирование подпапок.
- Поддержка форматов: `JPG`, `JPEG`, `PNG`, `WebP`, `GIF`, `BMP`, `SVG`, `AVIF`.
- Просмотр сеткой с настройкой размера миниатюр и полноэкранный режим (Lightbox) с навигацией клавишами `←` / `→` и `Esc`.
- Быстрое добавление и снятие тегов прямо на карточках, в Lightbox и массово для выделенных изображений (`Shift+клик` для диапазона).
- Локальное хранение всех тегов и динамических коллекций в `data/library.json` — исходные файлы фотографий не изменяются.
- Динамическая фильтрация по одному или нескольким тегам в режимах **И (все)** / **ИЛИ (любой)** и с **исключением (−)** тегов, а также сохранение фильтров в динамические коллекции.

## Запуск

### Без командной строки (Windows)
- Дважды кликните по [PictureTagger.vbs](PictureTagger.vbs) — сервер запустится в фоне без окна консоли, а приложение автоматически откроется в браузере. При повторном запуске просто откроется вкладка с приложением.
- Для удобства можно создать ярлык на рабочий стол: правый клик по `PictureTagger.vbs` → **Отправить** → **Рабочий стол (создать ярлык)**.
- Для остановки фонового сервера дважды кликните по [Stop-PictureTagger.vbs](Stop-PictureTagger.vbs).

### Через терминал

```bash
npm start
```

Или напрямую:

```bash
node server.js
```

После запуска откройте в браузере: `http://127.0.0.1:3456`
